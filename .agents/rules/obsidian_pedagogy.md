# Règle : Pédagogie Pro-Active (Obsidian)

Lors de la résolution d'un bug courant, de l'explication d'un Design Pattern (ex: EventBus, State Machine) ou de l'introduction d'un concept majeur de Godot/C# :
1. L'Agent **DOIT** générer un mini-cours explicatif au format Markdown.
2. Ce fichier doit être sauvegardé directement dans le dossier : `C:\Users\quent\Documents\Obsidian Vault\KingdomLike`.
3. Le format doit inclure un titre avec émoji, des sections claires et des métaphores visuelles.
4. Une fois le fichier créé via les outils, l'Agent doit inviter le joueur à aller le lire.
